# Release preparation workflow (no artifacts downloaded)

Reference material: [ComfyUI Windows ROCm 10.0 guidance](https://github.com/Comfy-Org/ComfyUI#amd-gpus-windows-rocm-100), [AMD ROCm compatibility matrix](https://rocm.docs.amd.com/en/latest/compatibility/compatibility-matrix.html), and [AMD PyTorch installation guidance](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html). The ComfyUI guidance names RX 9070 / 9070 XT gfx1201 and Python 3.13; it does not establish NAIA integration. The reviewed matrix lists Windows 11 25H2; 26H2 is not listed and remains unverified.

The data in `release-candidate-lock.json` is non-authoritative candidate metadata. Nine supplied candidate wheel URLs, filenames, versions and sizes are recorded, but the exact metadata has not yet been independently fetched and reviewed. Their SHA-256 values remain null and trust remains unverified. Do not copy the reported `rocm-bootstrap` or `rocm` observed hashes into `trust-policy.json`.

1. Independently resolve the candidate wheel filenames and links from AMD's official index for the `cp313-cp313-win_amd64` target; record the official metadata page, date, byte size and final URL. Compare against supplied candidate metadata. Do not follow cross-host redirects.
2. Download each artifact to `config/다운로드/` using a reviewed, non-executing fetch tool. Show actual byte counts and speed. Reject unexpected size, host, redirect, or truncation. Compute SHA-256 from the received bytes; this is a project-computed digest, not a vendor signature.
3. Inspect wheel `METADATA`, `WHEEL`, tags and `Requires-Dist`; resolve every dependency and build input with exact versions, direct URLs, sizes and full digests. Recheck package yanked status. Review the `rocm` sdist backend and lock build dependencies/output, or document a reviewed no-isolation build. Avoid globally forcing binary-only installation because `rocm` is source-only.
4. Independently review candidate files, package metadata, license/redistribution terms, OS/driver support and model/device mapping. Require two-person signoff for the computed digest list. Validate the Python installer signature/provenance separately.
5. Only after review, set exact allowlisted URLs and artifact digests; create a canonical manifest, review it, then set its SHA-256 pin in `trust-policy.json`. Put final distributable payloads in the signed package manifest. Keep AMD disabled for Windows 11 26H2 until AMD's matrix explicitly covers it and NAIA runtime tests pass.
6. No release candidate is complete until synthetic transaction tests pass, then actual compatible hardware tests verify ANIMA inference logs, GPU/VRAM activity, and absence of CPU fallback. The current suite does not prove abrupt power-loss recovery, junction rejection, UAC exit propagation, or the localized UI. This workflow does not run package code or install artifacts.
